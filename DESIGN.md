# Visual direction

Reading this as: a personal GitHub portfolio for developers, in an editorial terminal-adjacent style, dial ENERGY 3 / RHYTHM 3 / MOTION 2.

- Palette: warm charcoal, paper white, and restrained vermilion make the page feel tactile without turning the accent into decoration everywhere.
- Typography: Space Grotesk carries the name and repository titles with a distinct editorial voice; IBM Plex Mono is reserved for compact technical metadata.
- Layout: the owner explicitly chose an asymmetric Bento arrangement so repository size and hierarchy are visible at a glance.
- Glass surfaces: repository cards use translucent blur as requested; the owner explicitly approved the R-10 override.
- Motion: staggered reveals establish reading order, while a restrained spring hover makes repository links feel responsive without bouncing.
- Hero image: the actual public GitHub avatar is used as an account-specific visual after the owner approved it.
- Identity motif: a blinking caret beside the account name references a live editing cursor without presenting a fake terminal window.
